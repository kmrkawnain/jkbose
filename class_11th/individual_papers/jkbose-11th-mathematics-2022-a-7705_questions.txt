Q.01 [1 Mark] (Sets):
     If a set A contains n elements, then the total number of non-empty proper subsets of A is:

     (A) 2ⁿ
     (B) 2ⁿ - 1
     (C) 2ⁿ - 2
     (D) 2ⁿ⁻¹

Q.02 [1 Mark] (Complex Numbers):
     The modulus and principal argument of the complex number z = -1 - i√3 are:

     (A) |z| = 2, arg(z) = -2π/3
     (B) |z| = 2, arg(z) = 2π/3
     (C) |z| = 4, arg(z) = -π/3
     (D) |z| = 1, arg(z) = 4π/3

Q.03 [1 Mark] (Trigonometric Functions):
     Find the value of cos(75°) using the compound angle identity cos(A + B):

     (A) (√6 - √2)/4
     (B) (√6 + √2)/4
     (C) (√3 - 1)/2√2
     (D) Both (A) and (C)

Q.04 [1 Mark] (Permutations & Combinations):
     If ⁿC₈ = ⁿC₂, find the numerical value of ⁿC₂:

     (A) 45
     (B) 90
     (C) 10
     (D) 120

SECTION B : SHORT ANSWER TYPE - I
[Q. 05 to Q. 07 [6 Marks]]
================================================================================

Q.05 [2 Marks] (Linear Inequalities):
     Solve the linear inequality algebraically for real x: (2x - 1)/3 ≥ (3x - 2)/4 - (2 - x)/5.

Q.06 [2 Marks] (Binomial Theorem):
     Find the coefficient of x⁵ in the algebraic expansion of (x + 3)⁸ using the general term formula.

Q.07 [2 Marks] (Straight Lines):
     Find the perpendicular distance from the point P(2, 3) to the straight line 3x + 4y - 8 = 0.

[Q. 08 to Q. 10 [12 Marks]]
================================================================================

Q.08 [4 Marks] (Sequences and Series):
     In an Arithmetic Progression (AP), the first term is a = 5 and common difference d = 4. If the sum of first n terms is Sₙ = 116, find the value of n and the nth term.

Q.09 [4 Marks] (Conic Sections - Ellipse):
     Find the coordinates of the foci, the vertices, the length of major axis, minor axis, eccentricity, and the length of the latus rectum of the ellipse: x²/25 + y²/9 = 1.

Q.10 [4 Marks] (Limits & Derivatives):
     Find the derivative of f(x) = sin(x) from first principles (ab initio method) using the definition of derivative.

     cos(2x)cos(x/2) - cos(3x)cos(9x/2) = sin(5x)sin(5x/2).
